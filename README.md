# 🌡️ Conversor de Temperatura

Um programa de terminal desenvolvido em **C** para realizar conversões entre diferentes escalas termométricas. 

## 🚀 Funcionalidades

*   Conversão de graus Celsius para Fahrenheit e Kelvin.
*   Conversão de Fahrenheit para Celsius e Kelvin
*   Menu interativo e de fácil navegação.
*   Sistema adaptado com a biblioteca `windows.h` para garantir a visualização correta de acentos e caracteres especiais no terminal do Windows.

## 💻 Como Executar

Pré-requisito: É necessário ter um compilador C (como o GCC) instalado no seu computador.

1. Faça o clone deste repositório:
```bash
git clone https://github.com/eduardosimao-dev/conversor-de-temperatura.git
```
2. Entre na pasta do projeto
```bash
cd conversor-de-temperatura
```
3. Compile o código
```bash
gcc src/temperatura.c -o conversor
```
4. Execute o programa
```bash
./conversor
```
